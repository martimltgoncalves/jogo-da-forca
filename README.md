# Jogo da Forca em Python

Este é um projeto simples de terminal onde o jogador tenta adivinhar uma palavra secreta.

O objetivo deste projeto foi praticar lógica de programação em Python, especialmente estruturas como loops, funções e listas.

---

## Como jogar

- O programa escolhe uma palavra aleatória
- O jogador tenta adivinhar letra a letra
- Tens até 6 erros antes de perder
- Ganha-se ao descobrir todas as letras da palavra

---

## Como correr

```bash
python main.py
